# Mach Calculator – PWA

## מה יש בתיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה עצמה: מבנה, עיצוב וחישוב |
| `manifest.webmanifest` | "תעודת הזהות" של האפליקציה: שם, אייקון, תצוגת מסך מלא |
| `sw.js` | Service Worker: שומר את כל הקבצים במכשיר בביקור הראשון, כדי שהאפליקציה תעבוד אופליין |
| `icon-*.png`, `apple-touch-icon.png` | האייקונים למסך הבית |

## העלאה ל-GitHub Pages, בלי שורת פקודה

1. נרשמים ב-github.com.
2. לוחצים **New repository**, נותנים שם (למשל `mach`), בוחרים **Public** ולוחצים **Create**.
3. בעמוד ה-repository לוחצים **Add file → Upload files**, גוררים את כל הקבצים מהתיקייה (בלי התיקייה עצמה), ולוחצים **Commit changes**.
4. נכנסים ל-**Settings → Pages**. ב-Source בוחרים **Deploy from a branch**, ואז **main** ו-**/ (root)**, ולוחצים **Save**.
5. אחרי כדקה האתר זמין בכתובת `https://<שם-המשתמש>.github.io/mach/`.

## התקנה על אייפד או אייפון (צריך אינטרנט פעם אחת)

1. פותחים את הכתובת ב-**ספארי**.
2. מחכים עד שמופיע **"● זמין אופליין"**. זה הסימן שכל הקבצים נשמרו במכשיר.
3. לוחצים **שתף → הוסף למסך הבית**.
4. מעכשיו האפליקציה נפתחת מהאייקון במסך מלא, גם במצב טיסה.

## עדכון גרסה

משנים את הקוד, מעלים שוב את הקבצים, ומשנים ב-`sw.js` את `VERSION` (למשל ל-`mach-v2`). מכשיר שיתחבר לאינטרנט ויפתח את האפליקציה יקבל את הגרסה החדשה. מכשיר שלא מתחבר נשאר עם הגרסה הקודמת.

## הערות

- ב-repository ציבורי כל אחד יכול לראות את הקוד. יש בו רק נוסחאות של האטמוספרה הסטנדרטית, אז זה בסדר.
- החישוב: אטמוספרה סטנדרטית ICAO, FL הוא גובה לחץ, ו-IAS נחשב שווה ל-CAS (ללא תיקון שגיאת מיקום).
